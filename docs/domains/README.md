# Domains

A domain exists only when a coherent business problem, vocabulary, ownership boundary, invariants, and lifecycle justify it. This directory is intentionally not pre-populated with guessed bounded contexts.

Use [`DOMAIN_TEMPLATE.md`](./DOMAIN_TEMPLATE.md) when evidence supports introducing a domain. The first domain map must be derived from collaboration responsibilities and invariants, not from GitHub page names, package symmetry, or database tables.

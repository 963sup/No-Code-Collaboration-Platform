# Decision History Scope

- This subtree preserves superseded decisions and closed-gap evidence for provenance. It is never the current truth router.
- Mark historical state, date, replacement authority, and closure evidence explicitly. Do not silently rewrite history to resemble the current model.
- A closed gap must point to the executable evidence that closed it; reopening it belongs in `docs/IMPLEMENTATION_GAPS.md`.
- Current Product, Domain, architecture, and delivery contracts must not depend on historical prose for their meaning.

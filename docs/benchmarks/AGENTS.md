# Benchmark Evidence Scope

- This subtree records dated external observations used for comparison. Benchmarks are evidence, not Product admission, architecture authority, or current implementation status.
- Record source, observation date, conditions, and the precise behavior observed. Distinguish direct observation from inference.
- Admit a benchmark concept only through the Repository no-code collaboration test in the canonical Product/Ontology contracts.
- Do not preserve software-development-specific concepts through renaming, analogy, screenshots, or generic wrappers.
- Never capture credentials, tokens, private account data, or raw private Repository content.

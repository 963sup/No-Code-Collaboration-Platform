# Global navigation menu

- Trigger: top-left icon button with `aria-haspopup="dialog"`; opening it does not change the URL.
- Presentation: modal side drawer with backdrop, close button, selected-row treatment, icon plus label, separators, and `Top repositories` context shortcuts.
- Close behavior: close button, Escape, or backdrop; the prior URL and scroll context remain.
- Responsive: the same navigation model is retained at all four viewports; the drawer occupies a larger share of the screen on mobile.
- Observed destinations included Home, Issues, Pull requests, Repositories, Projects, Discussions, Codespaces, Copilot, and Explore. Their presence is evidence only.

# Issue create dialog

- Opens over the dashboard and keeps the dashboard URL; creation is a command, not a bookmarkable resource before an Issue identity exists.
- The dialog title makes Repository context explicit: `369sup/support`.
- Form composition: title, Markdown write/preview, description, formatting controls, file affordance, assignee, label, project, milestone, create-more option, cancel, and create.
- Context defaults from recent/top Repository discovery. This behavior must not be mistaken for ownership or authorization.
- The dialog was closed without submission.

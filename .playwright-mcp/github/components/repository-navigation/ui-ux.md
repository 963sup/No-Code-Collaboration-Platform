# Repository navigation

The owner and Repository form the stable context shown in breadcrumbs. Each accepted child path denotes a stable collaboration resource or projection. On mobile, only a subset of items is shown directly and the current/overflow items move behind `More`; the public URLs do not change. Source Code and executable Git/CI mechanics remain rejected. Data Commit/Branch/Diff/Change Proposal/Data Transfer names enter navigation only after their separate no-code Domain contracts and executable routes are accepted.

The current target slice intentionally renders only executable `Overview`, `Pages`, and authorization-gated `Activity`. It does not display disabled placeholders for accepted-but-unimplemented resources. At the current item count, horizontal overflow preserves all destinations without an additional `More` control; that control becomes necessary only when real accepted routes exceed the mobile width.

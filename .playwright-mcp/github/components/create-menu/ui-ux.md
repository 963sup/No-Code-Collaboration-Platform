# Create-new menu

- Desktop/laptop/tablet trigger: header plus button and chevron.
- Mobile trigger: nested plus button inside the user navigation dialog.
- The menu is an action list, not a domain resource. Most links are commands and therefore are not copied as canonical resource URLs in the target product.
- Selecting `New issue` opens a modal issue form on the current dashboard URL and selects `369sup/support` as the initial Repository context. No issue was submitted.
- Import is modeled as a process; repository, organization, and project creation are commands. Code-specific Gist and Codespace commands are rejected.

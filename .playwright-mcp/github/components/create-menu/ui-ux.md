# Create-new menu

- Desktop/laptop/tablet trigger: header plus button and chevron.
- Mobile trigger: nested plus button inside the user navigation dialog.
- The menu presents action entries rather than a stable content page.
- Selecting `New issue` opens a modal issue form on the current dashboard URL and selects `369sup/support` as the initial Repository context. No issue was submitted.
- Observed entries included Repository, Project, Organization, Gist, Codespace, and import/create actions; this sidecar makes no Product-admission claim.

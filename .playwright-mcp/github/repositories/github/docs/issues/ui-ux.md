# Issues collection

- Canonical resource is the Repository's Issue collection; search, status, sort, and page remain query state.
- Captured interaction states: default, hover, focus, filter popover/dialog, sort menu, page 2, loading, and empty.
- At 1440/1280/768 the issue navigation appears as a 256px supporting region; at 390px it is removed and primary filters collapse into compact controls.
- Filters update the query and remain refreshable/shareable; opening a popover alone does not create a new URL.
